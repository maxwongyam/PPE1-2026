### Lire et expliquer ce code
-Le script commence par vérifier que l'entrée comporte bien un argument et quitte si ce n'est pas le cas.
-Définition de 3 variables (fichiers contenant des URLs, deux variables servant de compteur.
-Le script lit ensuite le fichier ligne par ligne avec et répète avec une boucle while une vérification tant qu'il a une ligne non-vide.
-La vérication est la suivante : si la ligne commence par "http://" ou "https://" la variable $OK (ligne ressemblant à un URLs) augmente de 1 sinon c'est la variable $NOK (ligne ne ressemblant pas à un URLs) qui augmente de 1.
-Une fois toutes les lignes lues, le script affiche le nombre de ligne valides et non valides.
